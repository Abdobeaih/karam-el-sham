# Karam El Sham — Restaurant App

A modern restaurant web app for the Egyptian brand Karam El Sham: dynamic menu, cart management, search and filters, image popups, toast alerts and a global loading screen, backed by the Foodish API.

**Live:** https://karam-el-sham-restaurant-sigma.vercel.app

## Stack

- React 19 with React Router
- Redux Toolkit + React Redux for cart and menu state
- Tailwind CSS 4 (via the Vite plugin)
- Axios, react-hot-toast, Lucide icons

## Getting started

The app code lives in `Karam-ElSham-restaurant-main/`:

```bash
cd Karam-ElSham-restaurant-main
npm install
npm run dev
```

## Features

- Browse the menu by category with search and filters
- Product detail view with image popup
- Cart with quantity management and totals
- Toast notifications and a global loading screen
- Fully responsive layout
